（1）制作アプリのタイトル

「JavaScript Learning Lab｜Ver.2」

（2）制作アプリの説明（40文字程度）

JavaScript初心者が、アプリの操作を通してコードの処理過程を視覚的に学べるWebアプリ。

・画面左側でアプリを操作すると、右側にJavaScriptの実行コード・変数の変化・処理ログ・解説が段階的に表示される。

・Ver.2では、じゃんけんアプリに加えてタスク管理アプリを実装。配列・オブジェクト・真偽値・DOM操作を学べるようにした。

・コードを自分で読み解き、処理の仕組みや妥当性を理解して、AIに適切な修正指示を出せるようになることを目指す。

（3）工夫した点・こだわった点

・学習コンテンツの追加： タスク管理アプリを実装し、タスクの追加・完了状態の切り替え・リセットを通じて、配列やオブジェクト、真偽値の扱いを学べるようにした。

・LEVEL切り替え機能： じゃんけんとタスク管理を1つの画面で切り替えられるようにし、それぞれの操作状態を維持する仕組みを実装。

（4）難しかった点・次回トライしたいこと（または機能）

・複数アプリの管理： LEVELを切り替えても、それぞれのアプリの操作状態が維持されるようにすること。

・コードと解説の整合性： コード辞典の説明と実際のJavaScriptが一致しているか確認し、初心者にも理解しやすい表現にすること。

・AIとの共同開発： AIが生成したコードの必要性や実装方法を理解し、PRD・Design.mdと照らし合わせながら適切な修正指示を出すこと。

・次回トライしたいこと： LEVEL 3の電卓アプリを実装し、演算子・数値変換・条件分岐・関数の組み合わせについて学べる機能を追加する。
